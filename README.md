<h1>TopNotch</h1>
<br>
An interactive, unobtrusive notch for productivity.
<br>
Optimized for lower-end devices. Compatible with Windows 10 and 11.
</div>

## **Features**

 - Customization -> Change how the notch looks and behaves
 <div align="center"><img src="https://i.ibb.co/BVSD7M71/img7.png"></div>
 
 - Smooth Animations -> Seamless animations that run smoothly at all times and don't stress the system

<div align="center">
  <img src="https://i.ibb.co/84b56Fnh/img9.png">
  <br>
  <img src="https://i.ibb.co/ynj9cBD3/img8.png"> 
  </div>

 - Quick Actions -> System Actions (Shutdown, Restart etc), Link Shortener and Quick Image Sharing (requires a free (or paid) [ImgBB](https://api.imgbb.com) API key)
 - Usage Information -> View your CPU and RAM usage easily
 <div align="center"><img src="https://i.ibb.co/Fkrs3qXC/img1.png"></div>
 
 - Media & Device Controls -> View and control media
 <div align="center"><img src="https://i.ibb.co/HTbXsby3/img2.png"></div>
 
 - Notifications -> See your recent notifications (received while TopNotch is running)
 <div align="center"><img src="https://i.ibb.co/Z1bVKWD3/img3.png"></div>
 <div align="center"><img src="https://i.ibb.co/yB5h84Dq/img4.png"></div>
 
 - Launchpad -> Access your frequently-used apps
 <div align="center"><img src="https://i.ibb.co/j9V0yf9Y/img5.png"></div>
 
 - Clipboard -> Drag and drop files anywhere. Works with any programs, especially creative programs (Blender, Adobe CC, DaVinci Resolve etc)
 <div align="center"><img src="https://i.ibb.co/9kmJL6Gk/img6.png"></div>

## **Requirements**

 - Windows 10 or 11
 - [.NET 10.0 Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/thank-you/runtime-10.0.14-windows-x64-installer)
 - 30MB of free storage

Images taken on Windows 10 (to demonstrate the program's compatibility). Works just as great on Windows 11.
